💻 Featured Practice Project

ATM Machine Simulation

A console-based ATM simulation built using Java to practise fundamental programming concepts.

Features

- PIN verification
- Balance inquiry
- Deposit and withdrawal
- Insufficient balance validation
- Menu-driven interaction
- Exit option

Concepts Practised

- Variables and data types
- "Scanner" for user input
- Conditional statements ("if-else")
- Loops ("while")
- Basic input validation

Note: This is a beginner learning project. The PIN and balance are stored in memory and are not connected to a real banking system.
